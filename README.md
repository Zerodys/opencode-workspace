## 项目列表

### 🧩 tangram-game (七巧板网页游戏)

一个简单的七巧板拼图游戏，具有以下功能：

- **拖拽组件**：从左侧面板拖拽七巧板组件到画布
- **自动吸附**：组件靠近时自动粘合在一起
- **双击旋转**：双击组件可旋转 45 度
- **七种颜色**：每个七巧板组件都有不同的颜色
- **防重叠**：组件不能互相覆盖

#### 技术栈

- HTML5 Canvas
- Vanilla JavaScript
- CSS3

#### 运行方式

直接在浏览器中打开 `tangram-game/index.html` 即可。

#### 操作说明

1. 从左侧面板拖拽组件到画布区域
2. 拖动已放置的组件调整位置
3. 双击组件可旋转 45 度
4. 组件靠近时会自动吸附
5. 点击"重置"按钮重新开始
6. 点击"清空"按钮清除画布
